# Neural Network from Scratch

A fully functioning artificial neural network built from scratch in raw Python, coded manually using mathematical operations and basic Python programming tools like NumPy, instead of high-level machine learning frameworks like TensorFlow or PyTorch.

## About the project

This is a guided project-based learning project, following the book "Neural Networks from Scratch in Python" authored by Harrison Kinsley and Daniel Kukieła, as the framework for the concepts and code, while independently researching and debugging problems along the framework

The goal is to understand what happens inside a neural network, beyond the “black box” of high-level libraries, by implementing each component (layers, activation functions, forward pass) from scratch. This project is part of my effort to build a solid foundation of understanding in machine learning.
